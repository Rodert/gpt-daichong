# 下单前核验清单：价格、交付与售后

在付款前花两分钟完成下面的检查，通常能避免大部分可预见的问题。

![付款前核验订单与安全信息的插图]({{ '/assets/images/chongplus-20260903-151015-8064d72c-1.png' | relative_url }}){: .article-image}

## 付款前

- 确认商品对应的套餐、周期和适用账户类型。
- 确认展示价格是否包含服务费、税费或其他附加成本。
- 阅读退款、失败订单和重复付款的处理规则。
- 找到订单查询和客服入口，而不是只看到付款二维码或转账方式。
- 确认整个流程不要求交出密码、验证码、API Key 或会话凭证。

## 付款后

- 保存订单号、支付凭证和订单状态页面。
- 按订单中的官方或自助流程操作，避免从搜索结果进入仿冒页面。
- 在自己的 ChatGPT 账户内核对套餐状态。
- 有疑问时优先用订单号与服务方沟通，不要发送完整账户资料。
