# 账号安全清单：哪些信息绝不应交出去

订阅遇到问题时，最容易被忽略的是账号凭证。下面这份清单适用于官方、应用商店和第三方服务等所有路径。

## 永远不要提供的内容

- ChatGPT 或邮箱账户密码。
- 短信、邮箱或身份验证器的一次性验证码。
- API Key、恢复代码和身份验证器备份。
- 可直接登录账户的浏览器会话凭证、Cookie 或 Session 内容。

这些信息一旦泄露，风险不只是某次订阅失败，还可能包括历史对话、文件、支付信息和账户控制权的暴露。

## 用订单信息进行沟通

遇到交付或付款问题时，优先提供订单号、付款时间、商品名称和必要的脱敏截图。提交前先遮住邮箱、手机号、订单条码和支付账户余额等无关信息。

## 付款后立即完成三项检查

1. 回到自己的账户页面确认套餐状态。
2. 保存订单页、支付凭证和当时的服务条款截图。
3. 为重要账户开启双重验证，并检查近期登录记录。
